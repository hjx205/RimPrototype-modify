# Rim Prototype - 生物质核心（Biomass Nucleus）

本模组是基于原作者 **Ereko** 的《Rim Prototype - 生物质核心》制作的重制更新版，由 **Hjx** 接手维护。

## 模组简介

添加了一个新的神器（可以在虚空石碑附近找到）。小人使用后，会获得一根"生物质"状态条，并解锁三种武器形态：

- **利爪**（Claw）
- **利刃**（Blade）
- **护盾**（Shield）

除此之外没有其他获取方式，并且同一时间只能存在一个。

- 支持版本：RimWorld 1.5 / 1.6
- 前置 DLC：Anomaly（必需）
- 可选 DLC：Biotech（解锁额外的"进化者"异种人内容）
- PackageId：`Hjx.BiomassNucleus`

## 与原作的区别

在保留原版核心玩法（神器、生物质条、三种形态）的基础上，进行了大量重制与扩展：

- **重写源代码**：全部代码以 `Hjx_BiomassNucleus` 命名空间重写，内置 0Harmony，为后续扩展打好基础。
- **新增能力**：
  - 适应进化（Adapt Evolution）：根据受到的伤害进化出对应护甲
- **新增装备（1.6）**：原型装甲、原型头盔。
- **新增 Biotech 内容（1.6，可选）**：进化者（Evolver）异种人及其相关基因。
- **新增模组设置**：可分别调整利爪/利刃的伤害倍率与护甲穿透，以及是否忽略肢体缺失部位。
- **按 DLC 条件加载**：通过 LoadFolders 配置，未安装 Biotech 时自动跳过相关内容。

## 制作原因

这个 mod 一直是我很感兴趣的作品，但它长期停留在旧版本、无人继续更新。我不希望自己感兴趣的 mod 永远停留在低版本，所以决定亲自上阵，把它更新到当前游戏版本，并继续维护下去。

## 对我的意义

这是我制作环世界 mod 的**开始**。从零开始，我学习并掌握了大量环世界 mod 的制作经验——包括 C# 代码、Defs 配置、Patch 修改、Harmony 以及 DLC 兼容等。对我来说，这个 mod 有着很深远的意义。
